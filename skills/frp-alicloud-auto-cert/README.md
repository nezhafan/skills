# frp-alicloud-auto-cert

家用设备通过 **frp 内网穿透**暴露服务、域名托管在**阿里云**时，
在**本地**为该域名定期自动签发与续期 **Let's Encrypt 证书**。

## 这个 Skill 做什么

家用设备没有公网 IP，通常靠 frp 把服务转发到公网服务器。本 skill 解决这条链路上
最容易变旧的环节——**TLS 证书的签发与自动续期**。

```
家用设备（跑服务）─── frpc ───► 公网服务器（frps）─── 用户浏览器
        ▲
        └─ 证书在这里本地签发/续期（DNS-01 经阿里云 DNS）
```

## 为什么在「家用设备这侧」签

传统做法是在公网服务器上跑 certbot，但会有：

- 证书签在公网机、与真正跑服务的设备分离，要手动同步
- HTTP-01 验证需 80 端口可达，而 80 常被 frps 占用
- 换公网服务器就得重搭部署逻辑

改成**由家用设备主动签发**后：签发/续期/部署全在本地完成，与服务器解耦。

## 核心优势

- **DNS-01 验证**：经阿里云 DNS 完成，**不占用 80/443 端口**
- **不依赖公网服务器**
- **更换服务器仅需改一行 frpc 配置**
- 自动定期续期

## 适用场景

frp 内网穿透 + 阿里云域名 + 自建 HTTPS，
设备可以是树莓派 / NAS / 旧笔记本 / 软路由 / 迷你主机等
（任何长期开机、能出网、无公网 IP 的机器）。
