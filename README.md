# Skills — Hermes Agent 技能仓库

存放本人写的 Hermes Agent skill 文档，按使用场景分类。

## 目录

| 文件 | 说明 |
|------|------|
| `menu-lang.md` | Telegram 命令菜单语言切换（按钮式中/英切换） |
| `skills-list.md` | 列出系统所有已安装的 skill |

## 关于 Hermes Agent Skills

Hermes Agent skills 是 Markdown 格式的文档，包含 YAML 头信息和操作指引。这些文件放在 `~/.hermes/skills/` 目录下，agent 可自动加载并执行其中的步骤。

## 注意

- 本仓库中的 skill 专为 **Hermes Agent** 编写，格式与其他 AI agent（Claude Code、Cursor 等）不完全兼容
